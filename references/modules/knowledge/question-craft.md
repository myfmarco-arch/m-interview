# 问法设计

## 一、核心原则

“自然”不是一律改成白话。自然是指：问题使用受访者熟悉的语言层级，主持人能顺畅读出，受访者知道要回答什么。

问法需要同时判断：

1. 受访者掌握什么知识。
2. 研究员和受访者是否共享术语。
3. 本题要获得概念判断，还是亲历事实。
4. 受访者是否能直接回答。
5. 回答之后需要什么证据来支撑。

## 二、跨场景的知识关系分类

乔哈里视窗原本用于自我认知。这里借用它作为“研究员、专家和概念之间的知识关系”视角，不把它当成访谈方法或心理测量工具。

这个分类可以用于专家访谈、用户深访和座谈会。跨场景使用时，不把“专家”理解为职业身份，而把它理解为“受访者对当前主题的经验和知识”。

| 知识区域 | 研究员与受访者的关系 | 推荐问法 | 
| --- | --- | --- |
| 共同开放区 | 双方都熟悉概念和术语 | 可以直接使用术语，询问判断、框架和优先级 |
| 受访者经验区 | 受访者熟悉，研究员需要理解 | 请受访者解释自己的语言和判断，再追问案例、证据和边界 |
| 研究员命名区 | 研究员熟悉，受访者未必这样理解 | 不把术语写成前提，先用中性描述或请受访者自行命名 |
| 未知区 | 双方都没有稳定答案 | 用案例、情境、刺激物、对比和反例逐步探索 |

在专家访谈中，“受访者经验区”通常是专家掌握的行业、组织或专业知识。在用户深访中，它通常是用户自己的生活经验、使用习惯和个人判断。在座谈会中，它可能是某一部分参与者熟悉、另一部分参与者不熟悉的群体经验。

### 动态变化

这四个区域不是固定标签。访谈过程会改变知识关系：

- 受访者解释一个术语后，它可能进入共同开放区。
- 研究员给出一个概念后，如果受访者使用了自己的说法，原来的研究员命名区可能需要重命名。
- 讨论中出现不同经验时，原本的共同开放区可能暴露出群体差异。
- 刺激物、案例和现场操作可以把未知区转成可观察的具体经验。

因此，主持人需要根据对话实时调整用词，不要在整场访谈中固定使用同一套术语。

## 三、三类场景的使用方式

### 专家访谈

- 共同开放区：可以直接使用专业术语和宏观问题。
- 受访者经验区：请专家解释框架，再追问案例、证据、流程和边界。
- 研究员命名区：不要把内部战略框架、组织名称或研究分类当成专家的自然语言。
- 未知区：使用案例、反事实、对比和公开刺激物探索，不要求专家给出确定事实。

### 用户深访

- 共同开放区：可以使用双方都熟悉的产品或生活语言，但仍要追问具体经历。
- 受访者经验区：让用户先讲自己的说法，不急于把它翻译成 JTBD、痛点或需求。
- 研究员命名区：不要把“痛点”“需求”“价值”等研究词直接问给用户。
- 未知区：用最近一次经历、现场操作、截图、日志或具体情境代替抽象假设。

### 座谈会

- 共同开放区：可以作为群体讨论的起点，但先确认每个人理解是否相同。
- 受访者经验区：先让个人说明自己的经历，再比较不同参与者的语言和经验。
- 研究员命名区：不要用研究员分类引导群体形成共识。
- 未知区：使用图片、案例、排序或共创，让参与者共同形成可讨论的材料。

乔哈里视窗在这里的作用是选择提问的起点和语言层级，不替代关键事件、场景任务、群体比较或其他研究方法。

## 四、证据和自述边界

访谈得到的是受访者在本次对话中的叙述。不要把叙述自动改写成客观事实。根据研究目标选择证据：

```text
现场观察、实物、屏幕、设置、演示、截图
    > 最近一次具体事件的叙述
    > 一般化行为描述
    > 观点、评价和预测
```

这个顺序主要适用于行为、操作和使用频率问题。专家判断、身份意义和社会关系问题中，受访者的解释本身也是资料；此时要补案例、反例、边界和依据，不要强行要求现场实物。

对未来行为、价格和付费意愿的回答属于弱证据。不要把“会不会买”“愿意付多少”直接写成行为预测；继续追问真实经历、触发条件、替代方案和不能接受的条件。

如果只有自述，主持人可以在记录中标记“受访者自述”，并继续问：

- “您是根据哪一次经历这样判断的？”
- “您刚才提到 A，后面又提到 B，听起来两种感觉都有。能多讲讲吗？”
- “当时有没有留下截图或者记录？”

不要在现场把前后差异当成错误来纠正。矛盾、摇摆和临时改变本身可能说明不同场景下有不同的规则。主持人先并列记录，访后再分析。

## 五、追问技巧和停止条件

追问不是重复主问题。根据现场回答选择一种动作：

| 技巧 | 用法 | 示例 |
| --- | --- | --- |
| 留白 | 受访者停顿但还没有结束时，先保持沉默 | 不急着替对方补句子 |
| 复述 | 用受访者原话确认含义 | “您刚才说‘不放心’，具体指哪一刻？” |
| 具体化 | 把抽象词落到事件、动作或结果 | “您说‘很方便’，具体少了哪一步？” |
| 穷尽 | 检查是否还有其他路径、人物或条件 | “除了这个方法，还有别的处理方式吗？” |
| 情绪 | 追问情绪出现的时刻和影响 | “您刚才笑了一下，当时发生了什么？” |
| 预期 | 区分事前期待和事后评价 | “使用前您期待什么？”必要时追问：“后来哪里不同？” |
| 演示 | 让受访者现场打开、操作或指认 | “请按当时的方式做一遍，我只观察不打断。” |

### 习惯和选择

问“为什么选择”前，先确认这是不是一次有意识的选择：

```text
这是您特意这么做的，还是一直以来就这么用？
大概从什么时候开始这样用的？当时怎么开始的？
有没有哪次没法这么做？那次怎么办的？
```

习惯通常在被打破时才会显现。换机、系统升级、出差或临时没有原设备，都是好的追问入口。

### 他人和关系

用户的行为可能由家人、同事、朋友、组织或圈子共同形成。需要时补问：

- “当时有人帮您拿主意吗？”
- “这件事是您自己操作的，还是有人帮忙？”
- “这台设备还有谁会用？”
- “有没有什么场合，您会特意不这样做？”

不要把“和谁”只当作背景字段。它可能是解释购买、使用、放弃和身份意义的关键。

### 受访者自己的说法

在进入研究员的分类前，先让受访者说自己的词：

- “您平时管这个叫什么？”
- “跟朋友说起这件事时，您一般怎么说？”
- “您手机里的这些东西，自己会怎么分？”

受访者的命名和分类是资料，不要急着翻译成“需求”“痛点”或 JTBD。

模块满足以下条件时停止，不为凑问题继续追问：

- 已覆盖该模块对应的核心研究问题。
- 行为或经历模块至少有一个具体事件或案例。
- 概念或战略模块至少有一项案例、判断依据、边界或取舍。
- 适用时，关键分支、失败或替代方案已经确认，或已确认与本模块无关。
- 受访者开始重复，新增追问不再增加信息。

核心叙事题先让受访者完整讲完，再补问细节。中间出现的线索先记在主持人自己的纸笔或会议笔记里，不要为了完成清单打断叙事。

## 六、非使用和放弃路径

不要用“没用过”结束研究。顺序是：相关任务 → 自然认知 → 提示后识别 → 尝试 → 停止 → 替代 → 重新采用条件。提示识别前先说一句常态化的话，例如“很多人平时不会用到这个页面，没见过很正常”。问法见方法卡 7A。不要求没有使用经历的人评价“操作是否流畅”或“长期是否有价值”。

## 七、专家访谈的概念问题

专家访谈可以使用以下类型的问题：

- 战略判断： “这个业务最关键的控制点是什么？”
- 专业框架： “您会如何拆解这个问题？”
- 组织判断： “这个变化对团队分工带来了什么影响？”
- 趋势判断： “未来一到三年最可能发生什么变化？”

这些问题不是错误。它们用于获取专家的概念模型和判断框架。

但概念问题不能是唯一证据。每个重要判断至少补一类追问：

- **案例：** “能讲一个真实项目吗？”
- **过程：** “当时具体怎么推进？”
- **依据：** “您根据什么做这个判断？”
- **边界：** “什么情况下这个判断不成立？”
- **取舍：** “如果资源减少，优先保留什么？”

示例：

```text
主问：[产品或业务]的战略控制点放在哪些方面？
追问：您为什么把这些看成控制点？
追问：哪个真实项目或决策体现了这一点？
追问：这个判断受哪些资源、指标或约束影响？
```

不要为了追求口语化，把专家的概念问题强行改成普通用户式的生活化假设。两种问法获得的证据不同：

- 概念问题获得专家的框架和判断。
- 案例问题获得事实和证据。
- 二者组合才能判断专家观点是否有实际支撑。

## 八、敏感或未知内容的降级顺序

```text
直接询问事实
  -> 询问范围、变化或判断逻辑
  -> 询问通用做法或行业经验
  -> 允许受访者只回答可公开部分
  -> 放弃该问题，转向其他证据
```

每次降级都要说明：“具体数字或名称不方便说也没关系，您可以只说大概，也可以跳过。”对方再次拒绝后，不换一种说法继续追问。

## 九、顺序与偏差

回答会被前面的问题、出示的材料和主持人的用词带偏。排顺序时按下面做：

1. **先宽后窄。** 先让受访者讲整件事，再问其中一步。先问“请您回忆一下那次换机的过程”，再问“照片是怎么迁移过来的”。
2. **先自发，后提示。** 先问受访者自己想到什么，再拿出功能名、品牌、选项或刺激物。提示过的内容，不能再算作“自发提到”。
3. **先经历，后评价。** 评价、打分和取舍放在讲完具体经历之后。
4. **刺激物放后。** 概念图、原型和竞品放在受访者讲完自己的经历之后。先不解释，先问第一反应。
5. **需要比较时用提示清单。** 结果要跨受访者比较时，自由讲完后用一行提示清单补问没提到的类别。例如：“刚才没提到的联系人、照片、聊天记录，当时是怎么迁移的？”已经说过的不再重复。

常见偏差和改法：

| 偏差 | 例子 | 改法 |
| --- | --- | --- |
| 预设前提 | “新系统是不是方便很多？”“最吸引您的是哪里？” | 去掉评价词，改问发生了什么：“换过来以后，哪件事的做法变了？” |
| 将来意愿 | “以后会不会用？”“愿意花多少钱？” | 问已经发生的事：“最近一次用得上它，是什么时候？当时怎么办的？” |
| 是非问 | “您满意吗？” | 改成开放问法。是非问只用来确认资格、确认经历或进入分支。 |
| 一题多问 | “您怎么选的，为什么选它，后来满意吗？” | 拆成主问和追问，一次问一件事。 |
| 社会期许 | 受访者讲“应该”怎么做，或只讲好的一面 | 开场说“好的不好的都可以直接说”；问具体某一次，不问“一般”。 |
| 发起方效应 | 知道是品牌方在做研究，评价偏客气 | 方案允许时不点名发起方；点名时在简报写明这个偏差，评价类结论更谨慎。 |
| 研究员术语 | “痛点”“需求”“场景” | 用受访者自己的说法。 |

假设性问题可以作为追问，例如“只能留三样的话，您留哪三样？”。它帮受访者把取舍说出来，但回答只当态度，不当真实行为或需求优先级。专家访谈里的反事实追问用来检验判断，不受这条限制。

## 十、访谈中的打分

打分在访谈里的作用是给出一个锚点，方便追问理由。

- 沿用团队问卷的量尺，常用 1–10 分。
- 打分后马上追问理由：“为什么是 7 分，不是 9 分？”“要到 9 分，还差在哪？”
- 可以比较同一个人前后两次打分，例如看原型之前和之后。
- 不汇总均值，不算比例，不排名。访谈样本太少，分数只帮助理解这个人。
