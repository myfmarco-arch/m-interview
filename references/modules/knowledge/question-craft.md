# 问法设计

## 一、核心原则

“自然”不是一律改成白话。自然是指：问题使用受访者熟悉的语言层级，主持人能顺畅读出，受访者知道要回答什么。

问法需要同时判断：

1. 受访者掌握什么知识。
2. 研究员和受访者是否共享术语。
3. 本题要获得概念判断，还是亲历事实。
4. 受访者是否能直接回答。
5. 回答之后需要什么证据来支撑。

## 二、知识关系（乔哈里视窗）

这里借用乔哈里视窗，判断研究员和受访者之间的知识关系。它只用来选提问起点和语言层级，不是访谈方法或心理测量工具，也不替代关键事件、场景任务、群体比较等研究方法。

| 知识区域 | 研究员与受访者的关系 | 推荐问法 |
| --- | --- | --- |
| 共同开放区 | 双方都熟悉概念和术语 | 可以直接使用术语，询问判断、框架和优先级 |
| 受访者经验区 | 受访者熟悉，研究员需要理解 | 请受访者解释自己的语言和判断，再追问案例、证据和边界 |
| 研究员命名区 | 研究员熟悉，受访者未必这样理解 | 不把术语写成前提，先用中性描述或请受访者自行命名 |
| 未知区 | 双方都没有稳定答案 | 用案例、情境、刺激物、对比和反例逐步探索 |

“受访者经验区”在专家访谈里是行业、组织或专业知识，在用户深访里是生活经验和使用习惯，在座谈会里可能只是部分参与者熟悉的经验。

四个区域会随对话变化。受访者解释过的术语，可以进入共同开放区；受访者用了自己的说法，就改用它的说法；刺激物、案例和现场操作，可以把未知区变成可观察的经验。主持人按对话实时调整用词，不在整场访谈中固定一套术语。座谈会里，即使是共同开放区的词，也先确认每个人理解是否相同。

## 三、证据和自述边界

访谈得到的是受访者在本次对话中的叙述。不要把叙述自动改写成客观事实。根据研究目标选择证据：

```text
现场观察、实物、屏幕、设置、演示、截图
    > 最近一次具体事件的叙述
    > 一般化行为描述
    > 观点、评价和预测
```

这个顺序主要适用于行为、操作和使用频率问题。专家判断、身份意义和社会关系问题中，受访者的解释本身也是资料；此时要补案例、反例、边界和依据，不要强行要求现场实物。

如果只有自述，主持人可以在记录中标记“受访者自述”，并继续问：

- “您是根据哪一次经历这样判断的？”
- “您刚才提到 A，后面又提到 B，听起来两种感觉都有。能多讲讲吗？”
- “当时有没有留下截图或者记录？”

不要在现场把前后差异当成错误来纠正。矛盾、摇摆和临时改变本身可能说明不同场景下有不同的规则。主持人先并列记录，访后再分析。

## 四、追问技巧和停止条件

追问不是重复主问题。根据现场回答选择一种动作：

| 技巧 | 用法 | 示例 |
| --- | --- | --- |
| 留白 | 受访者停顿但还没有结束时，先保持沉默 | 不急着替对方补句子 |
| 复述 | 用受访者原话确认含义 | “您刚才说‘不放心’，具体指哪一刻？” |
| 具体化 | 把抽象词落到事件、动作或结果 | “您说‘很方便’，具体少了哪一步？” |
| 穷尽 | 检查是否还有其他路径、人物或条件 | “除了这个方法，还有别的处理方式吗？” |
| 情绪 | 追问情绪出现的时刻和影响 | “您刚才笑了一下，当时发生了什么？” |
| 预期 | 区分事前期待和事后评价 | “使用前您期待什么？”必要时追问：“后来哪里不同？” |
| 演示 | 让受访者现场打开、操作或指认 | “请按当时的方式做一遍，我只观察不打断。” |

### 习惯和选择

问“为什么选择”前，先确认这是不是一次有意识的选择：

```text
这是您特意这么做的，还是一直以来就这么用？
大概从什么时候开始这样用的？当时怎么开始的？
有没有哪次没法这么做？那次怎么办的？
```

习惯通常在被打破时才会显现。换机、系统升级、出差或临时没有原设备，都是好的追问入口。

### 他人和关系

用户的行为可能由家人、同事、朋友、组织或圈子共同形成。需要时补问：

- “当时有人帮您拿主意吗？”
- “这件事是您自己操作的，还是有人帮忙？”
- “这台设备还有谁会用？”
- “有没有什么场合，您会特意不这样做？”

不要把“和谁”只当作背景字段。它可能是解释购买、使用、放弃和身份意义的关键。

### 受访者自己的说法

在进入研究员的分类前，先让受访者说自己的词：

- “您平时管这个叫什么？”
- “跟朋友说起这件事时，您一般怎么说？”
- “您手机里的这些东西，自己会怎么分？”

受访者的命名和分类是资料，不要急着翻译成“需求”“痛点”或 JTBD。

### 停止条件

模块满足以下条件时停止，不为凑问题继续追问：

- 已覆盖该模块对应的核心研究问题。
- 行为或经历模块至少有一个具体事件或案例。
- 概念或战略模块至少有一项案例、判断依据、边界或取舍。
- 适用时，关键分支、失败或替代方案已经确认，或已确认与本模块无关。
- 受访者开始重复，新增追问不再增加信息。

核心叙事题先让受访者完整讲完，再补问细节。中间出现的线索先记在主持人自己的纸笔或会议笔记里，不要为了完成清单打断叙事。

## 五、非使用和放弃路径

不要用“没用过”结束研究。按方法卡 7A 的顺序问：相关任务 → 自然认知 → 提示后识别 → 尝试 → 停止 → 替代 → 重新采用条件。不要求没有使用经历的人评价“操作是否流畅”或“长期是否有价值”。

## 六、敏感或未知内容的降级

先直接问事实。对方明确拒绝后，最多降级一次（`ethics.refusal-limit`），从下面选一种问法：

- 只问范围、变化或判断逻辑。
- 只问通用做法或行业经验。
- 只请对方说可以公开的部分。

降级时说明：“具体数字或名称不方便说也没关系，您可以只说大概，也可以跳过。”对方再次拒绝，就放弃这个问题，转向其他证据，不换一种说法继续追问。

## 七、顺序与偏差

回答会被前面的问题、出示的材料和主持人的用词带偏。排顺序时按下面做：

1. **先宽后窄。** 先让受访者讲整件事，再问其中一步。先问“请您回忆一下那次换机的过程”，再问“照片是怎么迁移过来的”。
2. **先自发，后提示。** 先问受访者自己想到什么，再拿出功能名、品牌、选项或刺激物。提示过的内容，不能再算作“自发提到”。
3. **先经历，后评价。** 评价、打分和取舍放在讲完具体经历之后。
4. **刺激物放后。** 概念图、原型和竞品放在受访者讲完自己的经历之后。先不解释，先问第一反应。
5. **需要比较时用提示清单。** 做法见研究设计服务的“SRQ 覆盖”。例如自由讲完后补问：“刚才没提到的联系人、照片、聊天记录，当时是怎么迁移的？”已经说过的不再重复。

常见偏差和改法：

| 偏差 | 例子 | 改法 |
| --- | --- | --- |
| 预设前提 | “新系统是不是方便很多？”“最吸引您的是哪里？” | 去掉评价词，改问发生了什么：“换过来以后，哪件事的做法变了？” |
| 将来意愿 | “以后会不会用？”“愿意花多少钱？” | 问已经发生的事：“最近一次用得上它，是什么时候？当时怎么办的？” |
| 是非问 | “您满意吗？” | 改成开放问法。是非问只用来确认资格、确认经历或进入分支。 |
| 一题多问 | “您怎么选的，为什么选它，后来满意吗？” | 拆成主问和追问，一次问一件事。 |
| 社会期许 | 受访者讲“应该”怎么做，或只讲好的一面 | 开场说“好的不好的都可以直接说”；问具体某一次，不问“一般”。 |
| 发起方效应 | 知道是品牌方在做研究，评价偏客气 | 方案允许时不点名发起方；点名时在简报写明这个偏差，评价类结论更谨慎。 |
| 研究员术语 | “痛点”“需求”“场景” | 用受访者自己的说法。 |

假设性问题可以作为追问，例如“只能留三样的话，您留哪三样？”。它帮受访者把取舍说出来，但回答只当态度，不当真实行为或需求优先级。专家访谈里的反事实追问用来检验判断，不受这条限制。

## 八、访谈中的打分

打分只作追问的锚点，规则见 `evidence.rating`。沿用团队问卷的量尺，常用 1–10 分。打分后马上追问：“为什么是 7 分，不是 9 分？”“要到 9 分，还差在哪？”可以比较同一个人前后两次打分，例如看原型之前和之后。
