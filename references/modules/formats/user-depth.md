# 用户深访

## 适用对象

个人用户、使用者、购买者或未使用者。目标是理解个人经历、行为路径、场景、判断和替代。

## 核心证据

- 最近一次或典型事件。
- 任务、场景、动作和结果。
- 选择、放弃、失败和替代。
- 受访者自己的语言、分类和评价标准。

## 推荐节奏

```text
开场与资格确认 → 当前状态 → 最近一次经历 → 关键路径或场景 → 评价、取舍与替代 → 总结收尾
```

先让受访者完整讲述，再补时间、人物、动作和结果。时间不足时保留最近一次事件、失败或替代、关键评价标准和收尾。

## 场景专属规则

- 购买：从触发和购买路径进入，再问比较、取舍、犹豫和最终决定。
- 使用：从典型的一天或最近一次任务进入，再问频率、环境、他人和失败。
- 非使用或流失：不要以“没用过”结束，按方法卡 7A 的非使用路径问。
- 共同决策或共用：补问谁一起决定、谁帮忙、和谁共用、在谁面前会或不会这样做。
- 身份或社会意义：从具体场合、在场他人和实际反应进入，不直接追问抽象意义。
- 行为问题优先使用现场操作、屏幕、设置、截图或实物；没有现场证据时标明是受访者自述。
- 现场操作：先说明不是能力测试，允许跳过私人内容。
