# 专家访谈

## 适用对象

掌握组织、行业、专业流程、战略决策或技术判断的知情者。专家身份由当前主题的经验和知识决定，不等于职位名称。

## 核心证据

- 专家的概念模型和判断框架。
- 真实案例、决策过程、资源取舍和组织约束。
- 判断依据、指标、边界、反例和可能变化。
- 本人经验、团队经验、行业观察和预测之间的区别。

## 推荐节奏

```text
开场与身份边界 → 主题框架 → 关键案例 → 决策和过程 → 约束、取舍与反例 → 趋势或未来判断 → 总结收尾
```

专家可以概念先行。重要判断必须继续追到案例、过程、依据、边界或取舍，不能停留在口号和抽象结论。

## 问法规则

- 研究员和专家共享术语时，可以直接使用概念问题。
- 研究员命名的内部分类不写成专家必须接受的前提。
- 外部专家不方便披露时，允许回答范围、变化、公开案例或匿名经验。

## 场景专属规则

- 战略研究：用大话题牵引讨论，再落到控制点、决策、资源和指标。
- 组织研究：追角色边界、协作关系、流程重建和决策机制。
- 技术或专业研究：追标准、约束、失败模式、替代和适用边界。
- 内部专家：说明内容用途、是否署名以及是否会反馈给管理者。
- 外部专家：包括在职专家、前雇员和独立专家。开场确认身份、立场、匿名和可公开范围。外部在职专家（尤其是竞对员工）要在首轮确认：是否向受访者披露发起方、约访渠道的合规要求；这两项不能按“未提供就不点名”默认处理。
- 涉及 NDA 时，改问通用方法、判断逻辑、公开案例或匿名化经验。
- 成功案例后补失败案例、反例或不成立的条件。
