# 座谈会

## 适用对象

一组具有相关资格的参与者。目标是理解群体语言、差异、互动、刺激物反应和共同形成的判断。

## 核心证据

- 每位参与者的独立经历和判断。
- 不同经验、分歧和少数意见。
- 参与者如何回应、修正或影响彼此。
- 讨论前后的变化，以及共创或排序过程中的理由。

## 推荐节奏

```text
开场与规则 → 个人表达 → 轮流比较 → 小组讨论或刺激物 → 分歧与少数意见 → 独立回填 → 总结收尾
```

先个人、后群体。排序、投票或共创前先让每个人独立判断。人数较多时写明轮次和每轮时间。

## 问法规则

- 每道需要逐人回答的问题写明“轮流”；开放讨论写明“自由讨论”。
- 不要求参与者替研究员总结群体差异。
- 记录少数意见、沉默、讨论后的变化和未达成共识的地方。
- 刺激物先独立观察或选择，再邀请回应他人。

## 场景专属规则

- 概念评价：个人初看 → 理解检查 → 场景讨论 → 顾虑 → 群体比较。
- 需求共创：个人场景 → 问题卡片 → 小组聚合 → 方案生成 → 优先级和匿名补充。
- 敏感内容：默认不要求公开展示个人屏幕、相册、收入、价格或私人对话。
- 多个刺激物轮换展示顺序，记录个人初始选择和讨论后的变化。
- 轮流发言时轮换起头人；允许参与者先听后说，再回到该参与者。
- 敏感内容可先写关键词，再用区间卡片、匿名纸条或第三人称情境讨论。
- 控场：准备邀请沉默者、限制单人发言和暂存争议的短话术。
- 90 分钟以上安排短暂休息。

## 触发的验证规则

- `group.individual-first`
- `group.no-consensus-claim`
- `ethics.group-privacy`
- `question.fact-first`
- `question.order`
- `question.no-hypothetical`
- `ethics.consent`
- `ethics.sensitive-exit`

## 不包含

座谈会不能替代多次个人深访。8 人座谈会不等于 8 次个人路径的样本。
