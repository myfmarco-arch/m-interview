# 用户深访：非使用与现场观察

追问是候选项，用法见 [方法索引](index.md) 的读取规则。

### 7A. 非使用、低频使用和放弃路径

**适用问题**

- 为什么用户没有使用、很少使用或试过后放弃某个功能、产品或服务。
- 用户实际任务是否存在，以及目标方案是否进入过考虑范围。

**核心产出**

- 相关任务和触发情境。
- 自然认知、提示后识别和尝试路径。
- 停止、放弃或不采用的原因。
- 当前替代方案和重新采用条件。

**推荐顺序**

> 任务 → 自然认知 → 提示后识别 → 尝试 → 停止/放弃 → 替代 → 重新采用条件。

**主问**

> 最近一次您想完成相关事情是什么时候？

必要时追问：当时是怎么处理的？

**追问**

- 当时是从哪里开始找的？
- 那时候想到过这个功能吗？
- 现在看到它，您觉得它是做什么的？
- 之前试过吗？
- [试过]：第一次是怎么试的？
- 在哪一步停下来的？
- 当时担心什么？
- 最后是怎么完成的？
- 这样多花了什么功夫？
- 什么情况下，您会想再试一次？

在提示识别前先正常化：

> 很多人平时不会划到这个页面，没见过很正常。您第一次看到它时，觉得它是做什么的？

如果研究员还不知道受访者怎么称呼这个对象，先问：

- “您平时管这个叫什么？”
- “跟朋友说起这件事时，您一般怎么说？”

**常见误区**

- 没用过就直接跳过，错过认知、尝试和替代信息。
- 要求没有使用经历的人评价操作流畅度或长期价值。
- 只问“为什么不用”，不先还原用户想完成的任务。
- 把“什么情况下会再试”的回答当成需求证据。它只是态度。


### 7B. 情境访谈和手机桌面巡游

**适用问题**

- 行为发生在真实环境中，回忆容易失真。
- 需要观察桌面、最近使用、设置、账号、内容和设备分工。

**核心产出**

- 现场环境、设备和内容线索。
- 实际操作路径、绕行和停顿。
- 受访者说法与现场行为的差异。

**主问**

> 请在您平时使用的设备上，按刚才说的方式做一遍。我会先观察，必要时再请您解释。

**追问**

- 您现在先看什么？
- 看完后，平时也从这里开始吗？
- 这个页面您平时主要用来做什么？
- 如果刚才不在这里，您通常会怎么找？
- 刚才哪些步骤是习惯操作，哪些是想了一下才操作的？
- 刚才实际操作时，有没有哪一步和您平时想的不太一样？

**执行要求**

- 先让受访者自然操作，再提示目标功能。
- 只记录经过同意的截图、屏幕或账号信息；不要求展示隐私内容。
- 只有录音时，主持人口述屏幕状态，避免画面信息丢失。

**常见误区**

- 把现场演示变成可用性测试，却没有定义任务和观察点。
- 主持人过早提示路径，导致自然行为消失。
- 忽略真实环境和屏幕内容中的隐私风险。
