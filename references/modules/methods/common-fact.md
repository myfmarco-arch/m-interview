# 通用事实还原方法

追问是候选项，用法见 [方法索引](index.md) 的读取规则。

### 1. 关键事件技术（CIT）

**适用问题**

- 用户为什么做出一次决定。
- 用户为什么改变态度。
- 用户什么时候第一次感到满意、失望或不信任。
- 用户为什么开始、停止或恢复使用。

**核心产出**

- 事件发生的背景。
- 用户的实际行为和决策过程。
- 影响行为的触发点。
- 事件造成的结果和态度变化。

**主问**

> 请回忆最近一次发生这种情况的经历，从头到尾讲一遍。

**追问**

- 这件事发生在什么时候、什么地点？
- 当时和谁在一起？
- 事情是怎么开始的？
- 您先做了什么？
- 中间出现了什么变化或困难？
- 哪个瞬间让您改变了看法或做了决定？
- 最后是怎么处理的？
- 结果怎么样？
- 现在回头看，最重要的影响是什么？

**常见误区**

- 直接问“您通常会怎么做”。
- 直接问“您为什么这样做”。
- 接受“很好”“很方便”“很麻烦”等没有事实的总结。


### 2. 时间线和历史回顾

**适用问题**

- 购买、换机、迁移和回流。
- 品牌印象或情感的变化。
- 产品使用习惯的形成。
- 人生阶段或设备角色的变化。

**核心产出**

- 事件顺序。
- 阶段之间的转折。
- 转折点对应的行为、信息或体验。
- 随时间变化的动机和评价标准。

**主问**

> 我们从现在往前回顾。请按时间顺序讲讲这几年发生过的变化。

**追问**

- 最初是什么状态？
- 什么时候第一次产生变化？
- 当时发生了什么？
- 变化前后分别怎么做？
- 哪段时间对后来影响最大？
- 有没有明显的上升、下降或转折？

**常用变体**

- 购买历程：触发 → 搜索 → 比较 → 购买 → 使用。
- 品牌情感曲线：初次认知 → 兴趣 → 体验 → 喜欢或失望 → 当前态度。
- 产品体验地图：使用前 → 启动 → 使用中 → 完成 → 使用后。
- 人生阶段：学生时期 → 工作时期 → 家庭变化后的阶段。


**常见误区**

- 只追问时间顺序，不追问每个阶段发生了什么。
- 把受访者现在的解释当成当时真实的决策依据。
- 忽略时间线中的中断、回流和反复比较。

### 3. 最近一次和典型案例法

**适用问题**

- 需要减少遗忘和泛化回答时。
- 需要获取可以写入报告的完整故事时。
- 需要比较成功案例和失败案例时。

**核心产出**

- 一到两个完整案例。
- 案例中的触发、行为、结果和影响。
- 成功或失败的具体条件。

**主问**

> 请讲一个最近一次、最典型或印象最深的例子。

**追问**

- 当时的背景是什么？
- 谁参与了？
- 您实际做了什么？
- 哪一步最关键？
- 什么地方成功或失败？
- 后来如何处理？
- 平时也这样吗，还是这次比较特别？

**常见误区**

- 只收集成功案例。
- 只问典型判断，不问具体案例。
- 用一个案例推断全部用户或全部组织。
