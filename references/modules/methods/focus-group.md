# 座谈会方法

追问是候选项，用法见 [方法索引](index.md) 的读取规则。

### 21. 群体规则和表达氛围

**适用问题**

- 敏感话题。
- 需要获得真实吐槽和需求。
- 参与者之间存在明显权力或表达差异。

**核心产出**

- 参与者可以公开讨论的范围。
- 影响表达的权力、身份和氛围因素。
- 个人经验、群体语言和敏感议题的表达方式。

**主持人做法**

- 先说明没有标准答案。
- 明确讨论范围和不讨论的内容。
- 说明资料保密和使用方式。
- 鼓励基于个人经验表达。
- 允许不同意见，不急于判断对错。

**主问**

> 请结合自己的经历说，不需要代表所有人。您先说说自己的情况。

**追问**

- 这是您自己碰到的，还是听别人说的？
- 其他几位有不一样的吗？
- 刚才谁说的，跟您的情况不太一样？

**常见误区**

- 开场就要求大家达成共识。
- 让一位参与者连续占用大部分时间。
- 把沉默理解为同意。


### 22. 自由联想和投射

**适用问题**

- 品牌印象。
- 难以直接描述的情绪和形象。
- 用户不愿直接表达的态度。

**核心产出**

- 用户自然使用的联想词和表达方式。
- 品牌或产品的人格、形象和情绪含义。
- 联想背后的具体经历、媒介和事件。

**主问**

> 提到这个品牌或产品，您第一时间想到什么？

**投射问法**

- 如果它是一个人，会是什么样的人？
- 如果它生活在您身边，会从事什么工作？
- 如果它是一种生活方式，会是什么样？
- 如果一个人选择它，您觉得这个人有什么特点？

**追问**

- 为什么会这样联想？
- 哪个产品、广告、活动或经历影响了您？
- 这是您自己的体验，还是听别人说的？
- 其他品牌在这方面有什么不同？

**常见误区**

- 把投射答案直接当成事实。
- 只记录形容词，不追问联想来源。
- 过早给出品牌属性选项。


### 23. 群体比较和差异讨论

**适用问题**

- 识别不同用户的语言差异。
- 比较不同品牌、产品或场景。
- 发现共识、分歧和少数意见。

**核心产出**

- 参与者之间的共同点和差异。
- 差异对应的场景、身份或经验条件。
- 少数意见和反例。
- 参与者听到他人观点后的变化。

**推荐顺序**

1. 先让每个人独立回答。
2. 记录每个人的关键词和案例。
3. 请参与者比较不同答案。
4. 主持人记录分歧可能对应的经历、任务或评价标准，不要求参与者替研究员归类。
5. 主持人复述听到的共同点和差异，请参与者补充事实。

**主问**

> 刚才几位说的不太一样，能各自讲讲是怎么碰到的吗？

**追问**

- 谁碰到过差不多的情况？
- 谁的情况正好相反？
- 您听到别人的回答后，有没有改变或补充？
- 您说的这种情况，一般是什么时候碰到的？

**常见误区**

- 先问“大家是不是都这样”。
- 只记录多数意见。
- 让参与者互相说服，而不是还原差异来源。


### 24. 成功故事、失败故事和一线案例

**适用问题**

- 门店、服务、产品转化和一线业务研究。
- 需要理解哪些体验促进或阻碍结果。
- 需要获得真实业务语言。

**核心产出**

- 一线人员观察到的真实案例。
- 促进或阻碍转化的具体因素。
- 竞品差异和可复制规律。
- 偶然因素与稳定机制的区分。

**主问**

> 讲一个因为这个功能，把单子谈成的例子。

必要时追问：有没有因为它没谈成的？

**追问**

- 用户当时是什么情况？
- 用户最关注什么？
- 哪个功能或体验影响了结果？
- 当时客户还看了别家的什么？
- 当时一线人员做了什么？
- 换个客户，这招还管用吗？


**常见误区**

- 只让参与者讲最成功的案例。
- 不问案例发生的条件和结果。
- 把个别一线经验直接归纳成普遍规律。

### 25. 座谈会中的刺激物、排序和共创

**适用问题**

- 让参与者比较多个概念或方案。
- 形成群体优先级。
- 共同定义理想产品或理想体验。

**核心产出**

- 个人选择和群体选择。
- 选择背后的场景、理由和顾虑。
- 讨论中的共识、分歧和取舍条件。
- 可用于产品定义的优先级和方案方向。

**可用工具**

- 图片、视频、产品原型。
- 关键词卡片。
- 功能贴纸。
- 个人排序后再集体排序。
- 小组共创画布。
- 匿名建议箱。

**推荐顺序**

> 个人独立选择 → 解释选择 → 小组比较 → 讨论分歧 → 集体排序 → 匿名补充。

**主问**

> 请先各自选出最重要的三个，写在卡片上，先不要讨论。

必要时追问：您为什么这样选？

**追问**

- 哪个是必须保留的？
- 哪个只在特定场景有价值？
- 哪个听着不错，但您想不起来什么时候用得上？
- 只能留一个的话，请各位先自己写下来。
- 谁的使用场景和其他人不同？

**常见误区**

- 直接进行集体投票，导致从众。
- 让表达能力强的人代替其他人完成选择。
- 只记录最终排序，不记录个人选择和分歧。
