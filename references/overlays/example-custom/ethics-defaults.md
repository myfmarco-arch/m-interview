# 示例团队标准同意信息

以下内容为虚构示例。团队使用时替换为已审定的真实信息。启用本 overlay 时，这些信息视为已确认；用户在请求里给出不同信息时，以用户为准。

| 项目 | 团队标准 |
|---|---|
| 发起方说明 | 开场说“我是示例公司用户研究团队的研究员”；盲测项目不说明品牌 |
| 研究用途 | 只用于内部产品研究 |
| 记录方式 | 征得同意后录音；线上访谈同时录屏，不要求共享手机屏幕 |
| 匿名边界 | 报告匿名，不出现姓名、手机号和可识别的截图 |
| 跳过和退出 | 任何问题都可以跳过，可以随时结束 |
| 后续安排 | 访谈结束后 3 个工作日内发放礼金；中途结束照常发放 |

标准开场话术：

> 您好，我是示例公司用户研究团队的研究员。今天想听听您的真实经历，没有标准答案，好的不好的都可以直接说。经您同意，我们会录音，只在内部做研究用，报告里不会出现您的姓名和手机号。不想回答的可以跳过，也可以随时结束。现在方便开始吗？
